Pipeline Architecture and APIs

Production system specification, configuration schemas, and REST developer endpoints.

REST API Endpoints
POST /api/pipeline

Executes complete end-to-end pipeline (Preprocess -> Summarize -> TTS -> Evaluate).

POST /api/summarize

BART/Pegasus abstractive summarizer with length constraints.

POST /api/synthesize

Converts text into normalized 22050 Hz speech audio.

GET /api/samples

Returns multi-domain conversation samples from database.

POST /api/mos/submit

Records ITU-T P.800 human subjective MOS evaluation ratings.

Developer cURL Example
curl -X POST "http://localhost:8000/api/pipeline" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Your long-form customer transcript...",
    "target_max_length": 75,
    "speaker": "default",
    "speed": 1.0
  }'
